Un proyecto académico con vocación de barrio

Esta aplicación se construyó como práctica evaluativa de Ingeniería Web, pero está pensada como si fuera el sistema real de una biblioteca pequeña: simple, honesto y funcional.

Quiénes somos

El Roble es una biblioteca de barrio ficticia creada para esta práctica. Representa el tipo de lugar donde un vecino se registra una vez y vuelve muchas veces a pedir prestado un libro distinto.

El sitio funciona con un servidor propio escrito en Node.js, sin frameworks de interfaz, y guarda cada registro y cada préstamo en una base de datos SQLite que persiste entre reinicios del servidor.

Propósito del sitio

Demostrar, con un caso de uso concreto, el flujo completo de una aplicación web con persistencia: páginas HTML semánticas, una hoja de estilos externa, un servidor que atiende rutas GET y POST, formularios validados en el cliente y en el servidor, y dos tablas relacionadas mediante un identificador.

El lector se registra primero; ese registro genera un identificador único. Ese mismo identificador es lo único que se vuelve a pedir cuando el lector solicita un préstamo, para no repetir datos que el sistema ya conoce.
